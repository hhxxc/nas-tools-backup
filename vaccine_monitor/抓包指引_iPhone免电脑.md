# iPhone 免电脑抓包（只用手机）

如果你不想开电脑，iPhone 上装个抓包 App 就能自己抓。抓完把结果发我，我帮你转配置。

---

## 一、选工具

| App | 说明 |
|---|---|
| **Stream** | 免费为主，界面最简单，抓 HTTPS 够用，导出 cURL 方便 ← **推荐先试这个** |
| **Proxyman** | 免费开始用，界面现代，接近 Charles 的体验 ← 也推荐 |
| **HttpCatcher（网球）** | 付费，功能全，导出格式多 |
| **Thor** | 付费，老牌，稳定性好 |

App Store 直接搜名字即可。都靠「装一个本地 VPN + 自己的根证书」来解密 HTTPS。

---

## 二、以 Stream 为例的完整步骤

1. **装 App**：App Store 搜 `Stream` 下载。
2. **开启抓包**：打开 App → 点「开始抓包 / Start Capture」→ 系统弹「Stream 想要添加 VPN 配置」→ **允许** → 输锁屏密码。
3. **装根证书**：App 内一般有「安装 CA 证书 / Install Certificate」入口 → 跳到 Safari 下载描述文件 → 允许下载。
4. **安装描述文件**：设置 → 通用 → **VPN 与设备管理** → 找到 Stream 的证书 → **安装**（输锁屏密码）。
5. **⚠️ 手工信任证书**（这一步漏了 HTTPS 全是乱码）：
   设置 → 通用 → **关于本机** → 拉到最底 → **证书信任设置** →
   把 Stream 那个开关**打开**。
6. **开始抓**：回到 Stream 点「开始抓包」，状态栏会出现 **VPN 图标**。
7. **操作目标页面**：打开江苏预防接种 APP → 进「儿童预防接种分时预约」→
   **切换日期 / 下拉刷新 / 点查询**，让它重新请求一次号源。
8. **导出**：回到 Stream → 找到那个返回号源列表的请求（可按域名或 `appoint`/
   `order`/`reserve` 之类关键字过滤）→ 点进去 → **导出 / 复制为 cURL**。

> 分不清哪个请求？看响应内容——里面有一堆**日期 + 时间段 + 剩余数/可约状态**
> 的那个就是它。

---

## 三、抓不到明文怎么办

按顺序排查：

| 现象 | 原因 | 处理 |
|---|---|---|
| 请求显示 `SSL`、`Connection closed`、无响应体 | 证书信任没开 | 回第 5 步打开开关 |
| 开了信任还是全都不出明文 | **APP 做了证书绑定（SSL Pinning）** | 见下 |

政务类 APP 做证书绑定是有可能的。**iPhone 上绕过证书绑定基本无解**（要越狱 +
frida），遇到就走这两条路：

1. **换微信小程序入口**：如果当地有微信公众号/小程序能预约（如「XX疾控」），
   那条流量抓起来容易得多。
2. **换一台安卓手机抓**：安卓侧绕过证书绑定手段成熟（root 后 frida/objection，
   部分机型改包即可）。
3. 或者……直接用 APP 自带的「接种通知提醒」，不折腾抓包。

## 四、抓完之后怎么接上脚本

iPhone 上复制出来的 cURL，**直接粘贴发给我**，我帮你转成 `config.json`。
或者你自己丢到电脑上跑：

```bash
cd D:\nas-tools-backup\vaccine_monitor
# 把 cURL 存成 curl.txt 放到这个目录
python curl2config.py curl.txt
```

---

## 五、两个提醒

- **脚本本身要 7×24 跑**，所以最终还是得有台常开的机器（你自己的电脑、
  你的 NAS 或云服务器）。iPhone 只负责「抓一次包」，不负责长期运行。
- 抓完记得**在 Stream 里停掉抓包 / 关掉 VPN**，否则手机上网可能变慢或异常。
